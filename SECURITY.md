# Security policy

Security fixes target the latest 2.x release. Older 1.x releases should be upgraded using the [migration guide](docs/MIGRATION.md).

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/kekaop/WebConnector/security/advisories/new) when it is available. If private reporting is unavailable, open an issue requesting a private contact channel without exploit details, credentials, IP addresses, request bodies or live server configuration.

Include the plugin version, Java/server version, affected feature, expected and observed behavior, and a minimal reproduction using disposable credentials and a test server. See the [security model](docs/SECURITY_MODEL.md) for supported trust boundaries.

## Русский

Исправления безопасности выпускаются для последней версии 2.x. Для 1.x используйте руководство по миграции. Сообщайте об уязвимостях приватно через GitHub, если функция доступна. Иначе создайте issue с запросом приватного канала связи без описания эксплуатации и без секретов. Укажите версии плагина, Java и сервера, затронутую функцию и воспроизведение на тестовом стенде.
