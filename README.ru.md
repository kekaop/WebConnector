# WebConnector

[English](README.md) · [Русский](README.ru.md) · [Скачать](https://github.com/kekaop/WebConnector/releases)

WebConnector связывает Minecraft-сервер с сайтом, магазином, Discord-ботом и другими плагинами. Действия задаются в YAML или Java, вызываются через защищённый HTTP API, а события отправляются во внешние сервисы через подписанные webhook.

Один JAR рассчитан на Paper **1.20.1–26.2**; совместимость с **26.3 экспериментальная**. Java: 17 для 1.20.1–1.20.4, 21 для 1.20.5–1.21.11, 25 для 26.1+. Используется общий Bukkit API без NMS. Подробности проверок — в [матрице совместимости](docs/COMPATIBILITY.md). Folia, прокси и клиентские загрузчики модов не поддерживаются.

## Возможности

- Несколько API-ключей со сроком действия, списками разрешённых действий и permissions.
- Проверка JSON, ограничение IP/CIDR, размера запросов, частоты вызовов и параллельных опасных операций.
- Java API через Bukkit `ServicesManager`; явное разрешение публикации Java-действий в HTTP.
- Очередь операций с UUID, request ID и постоянной защитой от повторов по `Idempotency-Key`.
- Консольные команды с проверенными параметрами, ограниченное удаление файлов и остановка сервера.
- Очередь webhook, HMAC-подпись, фильтры, отдельные адреса маршрутов и повторные попытки.

## Установка

1. Поместите `WebConnector-2.0.0.jar` из [релиза](https://github.com/kekaop/WebConnector/releases/latest) в `plugins/`.
2. Запустите сервер. Плагин создаст конфигурацию и случайный секрет в `plugins/WebConnector/config.yml`.
3. Настройте действия и отдельные ключи для клиентов. Не публикуйте конфигурацию с секретами.
4. Выполните `/webconnector reload`. Изменение порта, адреса, потоков и размера журнала требует перезапуска.

По умолчанию доступен только `ping`, адрес — `127.0.0.1:25575`. Удаление файлов и остановка сервера выключены. Для удалённого доступа хостинг должен предоставлять дополнительный порт либо обратный прокси.

При обновлении с 1.x необходима [миграция конфигурации](docs/ru/GUIDE.md#обновление-с-1x). NodeDashboard и ServerBootstrap остаются внешними клиентами. Skript подключается через сторонний HTTP-аддон.
