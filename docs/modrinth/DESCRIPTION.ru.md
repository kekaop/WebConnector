# WebConnector

Подключите Minecraft-сервер к сайту, магазину, Discord-боту и другим плагинам через защищённый HTTP API, публичный Java API и подписанные webhook.

WebConnector выполняет только заранее настроенные действия, проверяет JSON и права клиента, отслеживает операции и сохраняет idempotency key между перезапусками.

## Возможности

- Именованные ключи со сроком действия, списком действий и permissions.
- Ограничения IP/CIDR, размера запросов, частоты вызовов и времени выполнения.
- Проверка имён игроков, UUID, строк, целых чисел, boolean, enum и regex.
- Асинхронные операции, request ID, polling и постоянная защита от повторов.
- Подписанные webhook с фильтрами, отдельными адресами и повторными попытками.
- Java API через Bukkit ServicesManager; явная публикация Java-действий в HTTP.
- Опциональное удаление только разрешённых файлов и отдельная защита опасных действий.
- Перезагрузка действий, ключей и маршрутов без перезапуска сервера.

## Совместимость и установка

Один серверный JAR рассчитан на **Paper 1.20.1–26.2**; поддержка **26.3 экспериментальная**. Нужна Java 17 для 1.20.1–1.20.4, Java 21 для 1.20.5–1.21.11 и Java 25 для 26.1+. Клиентская установка не требуется. Folia и прокси не поддерживаются. У сторонних Skript-аддонов собственные ограничения версий.

Поместите JAR в `plugins/`, запустите сервер и настройте `plugins/WebConnector/config.yml`. Приватный секрет создаётся автоматически. По умолчанию HTTP слушает localhost и разрешает только `ping`; остановка сервера и удаление файлов выключены. Для внешнего доступа нужен дополнительный порт или обратный прокси хостинга. Изменения действий, ключей и маршрутов применяются через `/webconnector reload`.

Повторяя запрос выдачи награды, используйте прежний `Idempotency-Key`. При ошибке или таймауте сначала проверьте результат операции: выполненные внешние команды нельзя автоматически откатить.

WebConnector — интеграционный шлюз, без собственной панели и платёжного процессора. NodeDashboard, ServerBootstrap и Skript подключаются как клиенты.
